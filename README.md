# 📚 Library Management SQL

Welcome to the **Library Management SQL** project! This repository contains SQL scripts to design and manage a simple yet functional library database system. It's perfect for learning, academic projects, or as a base for more complex systems.

---

## 🧾 Features

- 📁 Database schema for a library system
- 📚 Tables for books, members, authors, loans, and more
- 🔑 Relationships with primary and foreign keys
- 📈 Sample queries for managing and retrieving data
- 🧹 Clean and well-commented SQL code

---

## 🏗️ Database Structure

The system includes the following main tables:

- `books`: Stores information about the books
- `authors`: Information about authors
- `members`: Details of library members
- `loans`: Records of book issues and returns
- `categories`: Genres or types of books
